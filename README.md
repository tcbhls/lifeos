# LifeOS — 本地隐私优先的个人健身、饮食与作息助手

LifeOS 是一款面向大众、**纯本地存储（Local-First）**、无需注册登录的现代极简健身与养生移动应用（Web + Capacitor Android APK）。所有体征档案、饮食流水、训练日志、作息记录与个人 API Key 均 100% 存储在用户自己的设备本地。

## 核心特性

1. **今日中枢 & 轻量化 RPG 自律体系**
   - 实时计算 BMR / TDEE、碳蛋脂目标与训练日动态加成；
   - 睡眠不足 6.5 小时自动触发「低电量恢复模式」提示减载；
   - 28 天活跃热力图、连续打卡天数、晨重周趋势自动热量微调、首页喝水一键撤销。
2. **健康饮食（吃什么 / 美食库 / 周边探店）**
   - 内置 54+ 全国常见中式简餐、轻食健身餐、全国连锁快餐（麦当劳/KFC/赛百味/萨莉亚等）与便利店补给营养库；
   - 按训练场景本地 0 延迟速配 + 一日三餐换一换 + 拍照/截图识图批量入库；
   - 全国 16 大连锁聪明吃指南 + 手机 GPS 定位 + 可选高德实时探店 / OSM 开源地图。
3. **科学五分化训练 & 64 动作 3D 解剖示范**
   - 默认提供「练背 · 练肩 · 练胸 · 练腿 · 有氧」五分化及多套模板一键切换，支持「随机塞核心」与「初始化（恢复本日默认 / 清空本日 / 重置全套）」；
   - 全库 64 个动作内置离线 3D 解剖肌群高亮动图 + 抖音 / B站真人教学直达；
   - 健身房专注记组模式，自动开启组间休息倒计时并估算下次双进阶重量。
4. **喝水折算与免打扰作息提醒**
   - 6 类饮品补水系数自动折算（白水 ×1.0、电解质 ×1.1、咖啡 ×0.8、奶茶 ×0.7 等）；
   - 自定义免打扰时段，同步至 Android 原生系统通知栏。
5. **全权限游离 AI 管家（端侧原生离线 + 云端 BYOK 双引擎）**
   - **App 内置端侧离线 AI**：APK 内直接打包 ARM64 原生 `llama.cpp` 推理引擎，支持一键下载轻量量化中文模型（Qwen3-0.6B / Qwen2.5-1.5B / Qwen3-1.7B）在手机本地离线运行，配合内置四季养生与运动营养 RAG 知识库，零隐私外泄；
   - **可选云端联网 AI（BYOK）**：支持用户自行配置免费智谱 GLM-4-Flash、Google Gemini、硅基流动、DeepSeek 或 OpenAI 兼容接口，解锁实时联网搜索与拍照识餐。

## 隐私与安全设计

- **无中心后端**：不收集任何用户画像、体重、饮食或位置记录；
- **零内置隐私密钥**：公开构建不包含任何开发者个人 API Key；
- **备份默认脱敏**：导出 JSON 备份默认自动剔除 `aiApiKey` 与 `amapWebKey`，可安心分享菜谱与训练方案；
- **一键抹除**：设置页提供二次确认的「清空全部本机个人数据」入口。

## 本地开发与构建

```bash
npm install
npm run dev        # 启动移动端开发预览
npm run lint       # oxlint 静态检查
npm run build      # TypeScript + Vite 生产构建
```

Android APK 打包（需配置 `JAVA_HOME` 与 `ANDROID_HOME`）：

```powershell
.\scripts\build-android.ps1
```
